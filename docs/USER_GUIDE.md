# 聊天问答使用说明

先由管理员完成数据库检查、知识训练与服务启动，再打开默认 http://localhost:8090。页面可打开但 /readyz 未就绪时，查询可能不可用。

问题尽量明确指标、日期、实体及分组，例如“统计每个机构2025年的成分血采集量”。业务词需存在于审核目录；未知条件、歧义时间与排序会要求补充信息，不会随意补造。

输入栏两种模式：

- 执行查询：生成并校验只读 SQL，然后返回限行数据。
- 仅生成 SQL：生成并校验 SQL，不查询业务数据；不代表跳过安全校验。

Enter 发送，Shift+Enter 换行。系统支持有限聚合能力，不支持的同比、环比、窗口和复杂派生指标会拒绝；需要这些能力时由管理员先定义口径、实现能力并评测。

结果区区分成功、需要补充信息、无法支持、SQL 校验失败、生成失败和服务不可用。相同原因不重复展示。截断提示表示只展示部分数据，不能把已观察行数当成全量统计。

侧栏系统与训练状态用于查看依赖、活动知识和最近训练质量；“训练”不代表修改了大模型权重。开发示例通过率也不是生产准确率。

普通用户反馈是待审材料，不自动进入可信示例。只有管理员独立审核并经过服务器校验后才可能晋升 Gold。生产浏览器登录使用短期会话，密钥不应存入聊天内容或浏览器本地持久存储。
