# Text2SQL 使用指南

本文档面向系统使用者，不参与模型训练。

## 支持的问题

当前知识覆盖采集事实和机构维度，适合查询：

- 某一时间范围内的采集人次或采集量。
- 按机构、城市进行汇总。
- 按全血、成分血进行过滤。
- 按已存在的血型、性别、年龄等字段过滤或分组。

推荐问题：

- 统计2025年各城市的全血采集量。
- 统计2024年每个机构的成分血采集人次。
- 统计杭州市各机构2025年的全血采集人次。

## 提问建议

一个清晰的问题通常应包含：

1. 指标，例如“采集人次”或“采集量”。
2. 时间范围，例如“2025年”。
3. 分组维度，例如“各机构”或“各城市”。
4. 必要过滤条件，例如“全血”“成分血”或具体城市。

“机构、单位、血站”可视为相近表达；“城市、地市”可视为相近表达。

## 拒答范围

以下问题应拒答或要求补充信息：

- 指标在数据库和指标目录中不存在。
- 问题要求使用不存在的表、字段或业务实体。
- 没有说明需要查询“人次”还是“采集量”，且上下文无法唯一判断。
- 不同采集类型的单位存在歧义，但问题要求直接合计。
- 用户要求执行写入、删除或结构变更操作。

系统拒答是安全行为，不应通过猜测表名或字段名强行生成 SQL。

## 结果审核

用户确认结果时，应同时检查：

- 时间范围是否正确。
- 采集类型过滤是否正确。
- 机构或城市过滤是否遗漏。
- 统计使用的是人次还是采集量。
- 分组粒度是否符合问题。

执行成功只表示 SQL 可以运行，不表示业务语义一定正确。
